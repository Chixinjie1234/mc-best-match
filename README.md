# mc-best-match
麦麦套餐最优搭配助手｜麦当劳MCP参赛项目

## 项目介绍
本项目基于麦当劳MCP能力开发，是一款智能点餐搭配助手。
自动拆解麦当劳单品、套餐食材成本，对比不同组合的单价、食材价值，帮用户筛选性价比最高的点餐方案，避开溢价套餐，合理搭配主食、小食与饮品。

## 核心功能
1. 单品成本拆解：面包、肉饼、酱料、包装成本估算
2. 套餐比价：对比套餐单独购买 vs 组合购买差价
3. 智能推荐：根据预算、口味偏好，输出高性价比点餐组合
4. 成本科普：分析外卖包装、门店房租人工等隐性成本

## 使用方式
接入MCP，直接对话提问，例如：
- 帮我分析赛百味早餐套餐成本
- 麦当劳哪款套餐性价比最高
- 单点还是买套餐更划算
